راهنمای استفاده از برنامه چاپ 16 عکس در برگ A4
================================================

نحوه نصب و اجرا:
----------------
1. ابتدا فایل "نصب نیازمندی ها.bat" را اجرا کنید
2. سپس فایل "اجرا کن.bat" را اجرا کنید

ویژگی های برنامه:
----------------
- افزودن فایل HTML تکی
- افزودن پوشه حاوی فایل های HTML
- استخراج خودکار عکس پوستر از فایل HTML
- استخراج عنوان و خلاصه داستان
- پیش‌نمایش صفحه A4
- ذخیره به صورت PDF
- چاپ مستقیم (نیاز به pywin32)

نحوه استفاده:
------------
1. برنامه را اجرا کنید
2. روی "افزودن فایل HTML" کلیک کنید
3. فایل های HTML مورد نظر را انتخاب کنید
4. پس از اضافه شدن 16 فایل، روی "پیش‌نمایش A4" کلیک کنید
5. برای ذخیره، روی "ذخیره PDF" کلیک کنید
6. برای چاپ، روی "چاپ" کلیک کنید

ساختار صفحه A4:
---------------
- 4 ستون و 4 ردیف (مجموعاً 16 عکس)
- هر عکس دارای شماره و خلاصه داستان
- عنوان بالای صفحه
- حاشیه مناسب برای چاپ

نکات مهم:
----------
- فایل های HTML باید دارای عکس پوستر باشند
- فرمت عکس پوستر: JPEG یا PNG با base64
- حداکثر 16 فایل قابل اضافه شدن است
- برای چاپ مستقیم، کتابخانه pywin32 نیاز است

عیب یابی:
---------
- اگر برنامه اجرا نشد، مطمئن شوید Python نصب است
- اگر خطای ImportError گرفتید، فایل "نصب نیازمندی ها.bat" را اجرا کنید
- اگر چاپ کار نکرد، از ذخیره PDF استفاده کنید

سازنده:
-------
ساخته شده با Python و tkinter
